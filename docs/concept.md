# memo

中学生むけの個人塾。数学と英語を基本にする。
教科書中心で指導を行う。基本的な思想として教科書を完全に理解すれば、大抵の志望校にいけるし、その後の受験の本目的での大学入試でも十分に戦えると思っている。
テスト対策、些末なテクニックなどはいっさいやらずに、本質的理解を教科書中心に行う。

より具体的には、

まず英語は、英語の教科書の英文は

- 単語は完全に日本語意味を暗記する。
- その暗記した日本語訳から英語を復元、かけるようにする。
- 教科書の本文英文はすべて、日本語訳が自分でできる。
- その自分で訳した日本語文から、もとの英文をすでかける
- ネイティブの人がしゃべったその教科書本文の英文を聞き取れて、ディクテーションができる。
- その教科書本文の英文を日本文訳を見ながらで、英語でしゃべれる

を3年間で、3冊の教科書の本文英文すべてできるようにする。それを確認するためのテストが塾でのメインの活動になる。
これをできるようにする、障害を取り除くのと、テスト、確認、モチベ管理、などが塾の主目的になる。

英語、勉強は、基本自分でやるもので、教えられるものではないが、方法論は教えられるというのが基本的なコンセプト。
英語に関しては、理論ではなくて、ある程度の量の英文を完全理解、完全暗記、暗唱できるレベルまでにする。
これができれば、高校、大人になっても英会話でこまることはない。

文法もメインの対象にはならない。ざっくり教えたりサポートすることはあってもそういうのはすべて学校の授業に任せる。
さらに、文法のテスト対策は、定期考査、受験でも、いっさいやらない。これは、自然にできるようになるというコンセプトである。

数学においても、基本同じである。教科書の本文を読んで理解する。そして、例題を解く。
これは少なくても２かいは自分の手で解いて、答案を出して、他者＝私が採点をする。

これも無限にあるテスト、類題を解いていくではなくて、教科書と英語と違って１冊ぐらいの副読本か学校で配布される問題週を
完璧に解けるまでをやる。丸暗記でも全然問題ないが、複数回正解しないといけないので、狭義の意味の丸暗記では対応できないような確認方法を取る。
一回のテストの範囲がある程度大きくなるから理解せずに暗記できないし、全部とければ、暗記とか、理解は問題ではなく、再現生があって解ければが目的でそれを理解と呼ぶ。

あと、基本的なスタンスとして、進むペースは人によってよいとする。つまり、確認テストをパスすれば、その次に学校の進度関係なくすすむ。
自分で教科書を読んで、上記ことを進めていく。ちょっと理解できない、腹落ちしないところは学校の進度関係なく、そこを理解、次にいけるまで、そこを何回もやる。

想定では、ほぼ毎日勉強する。それもガリ勉とか早期の受験対策とかではなく、普通にやることを１hぐらいほぼ毎日すれば、
英数に関しては、２年で教科書は終わるような進度を想定している。これはまったく無理ではなく、普通の生徒ができるし、それをサポートするのがこの塾の特色、特徴である。２年で終わって、３年になれば、受験対策専用に塾に行くことには全く問題はなく、むしろ、それを想定している。

この力徳英数塾は、学問とその方法論を教えるのが主目的で、受験対策が主目的になることはない。結果的に本質的な学習が、受験に最も効果的だからである。
また、それ専用の対応は他でやってもらうのが最も、それぞれを得意としてところとの棲み分け、win-winになる考える。

ただし、２年で中学３年分の英数がおわって生徒にたいして、希望するのであれば、高校カリキュラムに対しても同じスタンスで、２年で、高校範囲を終わらせることは継続できる。つまり、大学受験の主要英数２教科に関しては、こと教科書レベルに関しては、高校１年で終わらせることができるし、それを目標とする。
理解の判断基準としては、明確に教科書の内容を理解していて、例題、基本問題集を解けるとする。これはすうがくで。英語に関しては、中学と全く同じで、高校教科書をベースに同じことをやる。確認も全く同じにする。


英語のリスニングに関しては、教科書英文本文をTTSで複数の音源としてそれを使う。著作権の問題からそれを塾側で作成して配布することはやらない。
生徒かその親御さんが各教科書範囲をスキャンさせてそれをTTSにより音源にしそれを各個人がgoogle workspace, driveで個人用として保存できるようにする。その音源と使って塾側ではテストする。

## 具体的な塾での活動、家庭学習方法
英語の教科書の暗記、暗唱の方法論として

教科書本文を生徒個人がスマホで撮影しほ本てTextｔｓを

OCRで取得する。そこから、単語を抜き出し、英単語ー＞日本語訳のテストを生成する。
その英単語テストを自宅で学習し、塾でテストする。
英単語テストが合格すれば、

合格した英単語テストの生徒個人が作った、テストした日本語訳のリストを次の日本語訳 -> 英単語のテストを塾側で作成する。
前の訳単語テスト合格後に半自動で作成し、それを個人に配布して（Text、データ）自宅で学習。そのあと、塾で同じデータを使ったテストを実施。
